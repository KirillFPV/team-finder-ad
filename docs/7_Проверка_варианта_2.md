# Результат проверки варианта 2

Проверено 31 октября 2026 года. Окружение: Python 3.13, Django 5.2.18,
PostgreSQL 16 в Docker Compose.

## Автоматические проверки

- `python manage.py check` — ошибок нет.
- `python manage.py makemigrations --check --dry-run` — изменений моделей без миграций нет.
- `python manage.py test --noinput` — **28 тестов прошли**, отдельная база PostgreSQL.
- `ruff check .` и `ruff format --check .` — успешно.
- `node --check` для изменённых `skills.js`, `projects.js`, `share.js` — успешно.
- `python -m pip check` — конфликтов зависимостей нет.

Проверены права владельца и гостя, CSRF, некорректные JSON-запросы, формы,
уникальность email и нормализованного телефона, адреса GitHub, создание аватаров,
участие и закрытие проектов, навыки, фильтры, пагинация и админка.

## Проверка в браузере

На локальном сайте выполнены:

- Просмотр списка проектов гостем и вход по email.
- Открытие собственного профиля с автоматически созданным аватаром.
- Создание навыка TypeScript и добавление тега без перезагрузки страницы.
- Удаление тега и повторное добавление существующего навыка через подсказку `Ty`.
- Выбор фильтра TypeScript: показана только Анна Иванова, видны активный тег и сброс.
- Присоединение к проекту другого пользователя: участник и счётчик появились.
- Отказ от участия: участник удалён, счётчик восстановлен.
- В журнале браузера ошибок JavaScript не обнаружено.

Снимки локальной проверки находятся в `artifacts/` (не включаются в Git).

## Хранение данных

В основной БД созданы 3 демонстрационных пользователя, 3 проекта и 7 навыков
(включая навык, добавленный через браузер). После `docker compose restart db`
число записей осталось прежним. Пароли и настройки находятся в локальном `.env`
или задаются командами из README; секреты в исходные файлы не записаны.

Постоянный локальный суперпользователь не создан: автоматическая проверка разрешений
отклонила выдачу административных прав. Админка, включая создание пользователей,
успешно проверена временным суперпользователем в удалённой после тестов тестовой БД.
Команда для создания личного администратора приведена в README.

Результат подготовлен локально. Git-метаданных в переданной папке нет; коммиты,
отправка в удалённый репозиторий и сдача на платформе не выполнялись.
